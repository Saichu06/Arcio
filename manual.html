1.

Introduction to Internet of Things (IoT)

Foundational Theory

1.1 What is the Internet of Things?

The Internet of Things (IoT) refers to a networked ecosystem of physical objects—often termed "things" or "smart devices"—embedded with sensors, microcontrollers, actuators, and communication transceivers. These embedded systems collect real-world physical telemetry (such as ambient light, thermal gradients, acoustic waves, and relative humidity), digitize the observations, and transmit them across local or global communication networks to execute automated actuation or analytical decision-making without requiring direct human intervention.

In modern engineering practice, IoT bridges the divide between the continuous physical world and discrete cybernetic systems, enabling automated feedback loops, predictive industrial maintenance, smart grid management, precision agriculture, and autonomous environmental monitoring.

1.2 Four-Tier IoT Architecture Model

A standard academic and industrial IoT implementation is organized into four distinct functional tiers, flowing sequentially from physical observation to cloud computation. Click each tier below to examine its technical specifications:

Tier 1: Sensing Layer (Physical Observation)

Sensors are physical transducers that convert physical phenomena (heat, lumens, distance, pressure) into proportional electrical quantities (voltage, resistance, or capacitance changes). In ARCIO, sensors like the LDR (light-dependent resistor) and DHT22 capture live environmental states for microcontroller processing.

1.3 Microcontroller vs. Microprocessor Comparison

Understanding the architectural distinction between a Microcontroller Unit (MCU) and a Microprocessor (MPU) is fundamental to embedded system engineering:

Parametric Dimension Microcontroller (e.g., ESP32 / ATmega328P) Microprocessor (e.g., Intel Core / ARM Cortex-A)
Architectural Integration Single IC containing CPU, Flash Memory, SRAM, Timers, ADC, and GPIO peripherals. Standalone CPU; requires external RAM, ROM, I/O controllers, and power ICs.
Operating System Bare-metal C/C++ firmware or lightweight Real-Time Operating Systems (FreeRTOS). Full General Purpose Operating System (Linux, Windows, Android, macOS).
Power Dissipation Milliwatts (mW) to Microwatts (µW); ideal for remote battery/solar deployment. Watts (W) to tens of Watts; necessitates active cooling and substantial power.
Deterministic Latency Hard real-time deterministic hardware interrupt responses (< 1 microsecond). Non-deterministic thread scheduling dependent on kernel dispatch.
Primary Role in IoT Edge node sensor acquisition, PWM control, relay triggering, direct bus interfacing. Central gateways, heavy computer vision, large database servers, cloud analytics.

2.

ESP32 & Arduino Architecture

Hardware Platform

2.1 ESP32-WROOM-32 Technical Overview

The ESP32-WROOM-32 is a dual-core 32-bit Xtensa LX6 microprocessor operating at clock frequencies up to 240 MHz. Manufactured by Espressif Systems, it combines high-speed processing, low-power sleep modes, integrated 802.11 b/g/n Wi-Fi, and dual-mode Bluetooth (Classic + BLE) on a monolithic silicon die.

⚡ Theoretical Specification of ARCIO's Virtual ESP32 Core

• CPU: Dual-Core 32-bit Xtensa LX6 @ 240 MHz (Up to 600 DMIPS computing capability).
• Memory: 520 KB on-chip SRAM, 4 MB external SPI Flash memory.
• Analog Converters: 12-bit SAR ADC (Up to 18 channels, 0–4095 digital resolution).
• PWM Generator: 16 independent LEDC PWM hardware channels with programmable frequency and resolution (up to 16-bit).
• Logic Voltage: 3.3V DC logic high; GPIO pins are not 5V tolerant.

⚠️ Engineering Rule: Input-Only GPIO Pins (GPIO 34–39)

GPIO pins 34, 35, 36 (VP), and 39 (VN) belong to ADC1 and do not possess internal output driver transistors or internal pull-up/pull-down resistors. They can only be configured as INPUT or ANALOG. Attempting to execute pinMode(34, OUTPUT) or digitalWrite(34, HIGH) will produce a compiler or runtime error.

IoT Sensor & Actuator Component Reference

Datasheets & Theory

Every component in the ARCIO virtual inventory models physical semiconductor, electromechanical, and electroacoustic characteristics. Consult the technical reference cards below:

SEMICONDUCTOR OPTOELECTRONIC EMITTER

3.1 Light Emitting Diode (LED) & Current-Limiting Resistor

Used in Exp 01, 02, 03, 04, 08, 10
📘 Description & Physics

An LED is a P-N junction semiconductor diode that emits photons via electroluminescence when forward-biased. Electrons recombine with electron holes within the bandgap, releasing energy as light.

⚙️ Operating Characteristics

• Forward Voltage Drop ($V_f$): ~2.0V (Red), ~3.0V (Green/Blue).
• Forward Current ($I_f$): Recommended 10 mA – 20 mA.
• Polarity: Long leg = Anode (+), Short leg / flat edge = Cathode (-).

📐 Ohm's Law Resistor Calculation

Connecting an LED directly to a 3.3V or 5V rail without a current-limiting resistor causes thermal runaway and destroys the junction. Resistor value is computed via Ohm's Law:

$$R = \frac{V_{supply} - V_f}{I_f} = \frac{3.3\text{V} - 2.0\text{V}}{0.015\text{A}} \approx 86.6\,\Omega \implies \text{Standard } 220\,\Omega$$

In ARCIO, a 220Ω resistor is placed in series between the GPIO pin and the LED Anode.

MOMENTARY MECHANICAL TACTILE SWITCH

3.2 Tactile Push Button & Pull-Up Resistors

Used in Exp 02, 07, 10
📘 Description & Mechanism

A momentary SPST (Single Pole, Single Throw) tactile switch. When pressed, internal metal contacts bridge the circuit; when released, a mechanical spring returns the contacts to an open state.

⚙️ The Floating Pin Problem

A high-impedance microcontroller CMOS input pin left disconnected will act as an antenna, picking up electromagnetic ambient noise and oscillating randomly between 0 and 1.

🔌 Active-Low Logic & Internal Pull-Up

By configuring pinMode(pin, INPUT_PULLUP), the ESP32 activates an internal 45kΩ resistor to 3.3V:

  • Unpressed (Open): Pin reads HIGH (3.3V).
  • Pressed (Closed to GND): Pin reads LOW (0V).
Conditional evaluation: if (digitalRead(BUTTON_PIN) == LOW) { /* Pressed */ }
PHOTOELECTRIC VARIABLE RESISTOR

3.3 Light Dependent Resistor (LDR / Photoresistor)

Used in Exp 04, 10
📘 Photoconductivity Physics

An LDR is made of Cadmium Sulfide (CdS). When incident light photons strike the semiconductor, valence electrons are excited into the conduction band, decreasing electrical resistance.

• Total Darkness: Resistance RLDR ≈ 500 kΩ − 1 MΩ.
• Bright Sunlight: Resistance RLDR ≈ 100 Ω − 1 kΩ.

📐 Voltage Divider Configuration

Since microcontrollers measure voltage rather than pure resistance, the LDR is wired in series with a fixed 10 kΩ resistor (Rfixed):

Vout = VCC × [ Rfixed / (RLDR + Rfixed) ]

As light intensity increases, RLDR decreases, causing Vout to rise toward 3.3V (ADC count approaches 4095).

DIGITAL HYGROMETER & THERMISTOR SENSOR

3.4 DHT22 (AM2302) Temperature & Humidity Sensor

Used in Exp 05
📘 Sensor Construction

Contains a capacitive humidity sensing element, an NTC thermistor, and an integrated 8-bit microcontroller that outputs calibrated 40-bit digital frames over a proprietary single-bus line.

• Temperature Range: -40°C to +80°C (±0.5°C accuracy).
• Humidity Range: 0% to 100% RH (±2% accuracy).
• Sampling Period: 2.0 seconds minimum between reads.

ELECTROACOUSTIC PIEZO TRANSDUCER

3.5 Passive Piezoelectric Buzzer

Used in Exp 06, 10
📘 Passive vs. Active Buzzers

An active buzzer contains an internal oscillator and sounds a fixed single tone upon receiving continuous DC. A passive buzzer (used in ARCIO) has no internal oscillator and requires an AC square wave PWM signal to flex the ceramic disc and produce varying musical pitches and alarm frequencies.

⚙️ PWM Tone Generation Logic

By varying the PWM frequency in firmware, distinct alarm tones are produced:

• Low Pitch Alert: 1000 Hz (T = 1.0 ms).
• High Pitch Alert: 1500 Hz (T = 0.66 ms).
• Duty Cycle: Kept at 50% (128 / 255) for optimal acoustic resonance.

CLOSED-LOOP ELECTROMECHANICAL ACTUATOR

3.6 TowerPro SG90 Micro Servo Motor

Used in Exp 07
📘 Closed-Loop Feedback Control

The SG90 integrates a DC brushed motor, reduction gearbox, output spline, internal potentiometer feedback, and an analog control error circuit. It rotates accurately between 0° and 180°.

• Operating Voltage: 4.8V – 5.0V DC.
• Stall Torque: 1.8 kg-cm at 4.8V.

📐 50 Hz PWM Pulse Protocol

Position is governed by a 50 Hz (20 ms period) pulse width modulation signal:

  • 1.0 ms pulse width → 0° Position.
  • 1.5 ms pulse width → 90° Neutral Center.
  • 2.0 ms pulse width → 180° Maximum Position.
ACOUSTIC TIME-OF-FLIGHT TRANSDUCER

3.7 HC-SR04 Ultrasonic Distance Sensor

Used in Exp 08
📘 Sonic Burst & Echo Return

The sensor emits an 8-cycle ultrasonic burst at 40 kHz from its transmitter transducer (T). The acoustic wave travels through air, strikes an obstacle, and reflects back to the receiver transducer (R).

• Measurement Range: 2 cm to 400 cm (±3 mm accuracy).
• Trigger Pulse: 10 µs TTL pulse on Trig pin.

📐 Time-of-Flight (ToF) Distance Formula

The Echo pin outputs a high pulse whose duration (Δt) equals the round-trip travel time. With speed of sound in air v ≈ 340 m/s = 0.0343 cm/µs:

Distance (cm) = [ Δt (µs) × 0.0343 cm/µs ] / 2
GALVANICALLY ISOLATED ELECTROMAGNETIC SWITCH

3.8 5V Single-Channel Relay Module

Used in Exp 09
📘 Galvanic Isolation & Optocoupler

Relays enable low-voltage digital microcontrollers (3.3V) to safely switch high-voltage, high-current AC mains loads (230V AC / 10A). An internal optocoupler optical barrier isolates the ESP32 from high-voltage line spikes.

🔌 Contact Terminals
  • COM (Common): Connected to line power source.
  • NO (Normally Open): Connected to appliance. Closes when GPIO 23 is driven HIGH.
  • NC (Normally Closed): Connected to circuit when coil is unpowered.

Signal Processing

4.1 Binary Digital Logic (HIGH / LOW)

Digital signals represent discrete two-state binary logic: Logic 0 (LOW = 0.0V) and Logic 1 (HIGH = 3.3V). Digital inputs evaluate whether incoming voltage crosses the CMOS threshold.

4.3 Analog-to-Digital Converter (ADC) Quantization

The ESP32 incorporates successive-approximation (SAR) ADCs with 12-bit resolution ($2^{12} = 4096$ discrete quantization steps). The mathematical mapping from measured analog voltage ($V_{in}$) to digital integer count ($D_{ADC}$) is governed by:

$$D_{ADC} = \text{round}\left( \frac{V_{in}}{V_{ref}} \times 4095 \right) \quad \iff \quad V_{in} = D_{ADC} \times \frac{3.30\text{ V}}{4095}$$

Working with the ARCIO Simulator

Virtual Workspace Guide

The ARCIO simulation environment provides a browser-based, high-fidelity circuit simulator and C++ compiler. Follow the standard laboratory operating procedure:

  1. Component Placement: Drag components from the sidebar onto the virtual breadboard canvas. Snap pins into matching tie-points.
  2. Circuit Wiring: Click any component pin terminal or ESP32 GPIO header to initiate a jumper wire. Click the destination terminal to complete the connection.
  3. Color-Coded Wire Standards:
    • Red Wire: 3.3V / 5V DC Positive Power Rail.
    • Black / Dark Blue Wire: Ground (GND) Common Return.
    • Green / Yellow / White Wire: Digital GPIO & Analog ADC Signal Lines.
  4. Smart Inspector Pre-Flight Validation: Click the Smart Inspector button to verify circuit topology, identify short-circuits, and confirm pin mappings before starting simulation.
  5. Firmware Execution: Click Start Simulation. The real-time engine executes the C++ loop, drives virtual electronics, and outputs serial telemetry to the integrated console.

const int LED_PIN = 5;

⚠️ Common Mistakes & Troubleshooting in Experiment 01 ▼

• Reversed LED Polarity: If the Anode is wired to GND and Cathode to GPIO 5, the diode will be reverse-biased and will not light up.

• Missing Current-Limiting Resistor: Wiring GPIO 5 directly to the LED Anode can exceed the 40 mA maximum current rating of the ESP32 pin.

• Floating GND: Ensure the breadboard ground rail is connected to an ESP32 GND pin.

EXPERIMENT 03 · PULSE WIDTH MODULATION

PWM Hardware Channel LED Brightness Modulation

⏱️ Duration: 30 Mins 🏆 XP: 30 ⚡ Difficulty: Intermediate
🎯 Aim & Objectives

To configure the ESP32 LEDC PWM controller (Channel 0, 1000 Hz, 8-bit resolution) and modulate the average current delivered to an LED on GPIO 5 across 256 duty-cycle levels (0–255) to achieve smooth continuous dimming.

💻 Arduino C++ Source Code
exp03_pwm_dimming.inoLEDC Driver
const int LED_PIN = 5;
const int PWM_CHANNEL = 0;
const int PWM_FREQ = 1000;       // 1.0 kHz carrier frequency
const int PWM_RESOLUTION = 8;    // 8-bit resolution (0–255 levels)

void setup() {
  ledcSetup(PWM_CHANNEL, PWM_FREQ, PWM_RESOLUTION);
  ledcAttachPin(LED_PIN, PWM_CHANNEL);
}

void loop() {
  // Fade in
  for (int duty = 0; duty <= 255; duty++) {
    ledcWrite(PWM_CHANNEL, duty);
    delay(8);
  }
  // Fade out
  for (int duty = 255; duty >= 0; duty--) {
    ledcWrite(PWM_CHANNEL, duty);
    delay(8);
  }
}

EXPERIMENT 05 · DIGITAL SENSOR PROTOCOLS

DHT22 Digital Temperature & Relative Humidity Telemetry

⏱️ Duration: 35 Mins 🏆 XP: 30 ⚡ Difficulty: Intermediate
🎯 Aim & Objectives

To interface a high-precision DHT22 (AM2302) digital environmental sensor with the ESP32 on GPIO 17, decode its single-bus 40-bit data packet, and print real-time temperature and relative humidity over the Serial Monitor.

💻 Arduino C++ Source Code
exp05_dht22.inoDHT Sensor Protocol
#include "DHT.h"

const int DHT_PIN = 17;
#define DHT_TYPE DHT22

DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  float humidity = dht.readHumidity();
  float temperature = dht.readTemperature(); // Celsius

  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("Error: Failed to read from DHT22 sensor!");
  } else {
    Serial.print("Temp: ");
    Serial.print(temperature, 1);
    Serial.print(" °C | Humidity: ");
    Serial.print(humidity, 1);
    Serial.println(" % RH");
  }
  delay(2000); // 2-second sampling interval
}

exp07_servo.inoESP32Servo Library
#include 

Servo myServo;

EXPERIMENT 08 · TIME-OF-FLIGHT SENSING

HC-SR04 Ultrasonic Distance Measurement & Proximity Alarm

⏱️ Duration: 30 Mins 🏆 XP: 35 ⚡ Difficulty: Intermediate
🎯 Aim & Objectives

To generate a 10 µs trigger pulse on GPIO 5, measure the return echo duration using pulseIn(GPIO 18, HIGH), compute distance in centimeters via the speed of sound formula, and trigger an alert LED on GPIO 2 when an obstacle is within 20 cm.

💻 Arduino C++ Source Code
exp08_ultrasonic.inoTime-of-Flight Driver
const int TRIG_PIN = 5;
const int ECHO_PIN = 18;
const int LED_PIN = 2;
const int THRESHOLD_CM = 20;

void setup() {
  Serial.begin(115200);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Clear trigger
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  // Send 10us acoustic burst trigger
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  // Measure echo pulse width in microseconds
  long duration = pulseIn(ECHO_PIN, HIGH);
  int distanceCm = duration * 0.0343 / 2;

  Serial.print("Measured Distance: ");
  Serial.print(distanceCm);
  Serial.println(" cm");

  digitalWrite(LED_PIN, distanceCm < THRESHOLD_CM ? HIGH : LOW);
  delay(100);
}

💻 Arduino C++ Source Code
exp10_smart_home.inoMulti-Sensor Logic
const int BUTTON_PIN = 4;
const int LED_PIN = 5;
const int LDR_PIN = 34;
const int BUZZER_PIN = 12;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);
  int lightLevel = analogRead(LDR_PIN);

  if (buttonState == LOW) {
    // Priority Condition: Manual Emergency Alarm
    digitalWrite(LED_PIN, HIGH);
    digitalWrite(BUZZER_PIN, HIGH);
  } else if (lightLevel < 2048) {
    // Automatic Night Condition: Illuminate LED without buzzer
    digitalWrite(LED_PIN, HIGH);
    digitalWrite(BUZZER_PIN, LOW);
  } else {
    // Normal Daylight Condition: System Standby
    digitalWrite(LED_PIN, LOW);
    digitalWrite(BUZZER_PIN, LOW);
  }
  delay(100);
}

Laboratory Troubleshooting & Common Mistakes

Diagnostic Matrix
Observed SymptomUnderlying Physical / Logical CausePrescribed Laboratory Resolution
LED Fails to Illuminate Reversed polarity or missing ground connection. Verify Anode is wired to the GPIO node and Cathode is grounded to the common GND rail.
Button Input Oscillates Floating input pin picking up electromagnetic noise. Configure pinMode(pin, INPUT_PULLUP) or add an external $10\,\text{k}\Omega$ pull-up resistor to 3.3V.
ADC Value Stuck at 4095 Analog pin tied directly to 3.3V or open circuit on ground leg. Inspect voltage divider wiring; ensure the fixed $10\,\text{k}\Omega$ resistor connects to the GND rail.
DHT22 Returns NaN Readings Missing pull-up resistor or sampling faster than 2.0s. Ensure a $10\,\text{k}\Omega$ pull-up resistor bridges VCC and DATA, and maintain a 2000 ms loop delay.
Servo Motor Jitters / Resets Insufficient current from 3.3V regulator during motor stall. Power the SG90 servo from the 5V (VIN) rail rather than the 3.3V output rail.
Ultrasonic Returns 0 cm Trig and Echo pins inverted in wiring or code. Verify Trig is wired to GPIO 5 and Echo is wired to GPIO 18.
