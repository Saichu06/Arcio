Chapter 02

What is the Internet of Things (IoT)?

Learn the definition, foundational concepts, and real-world industrial relevance of connected IoT systems.

The Internet of Things (IoT) refers to a network of physical devices (“things”) embedded with sensors, processing power, software, and communication hardware that connect and exchange data with other devices and central cloud systems over the Internet.

Core Elements of an IoT Ecosystem

SEN
1. Perception (Sensory Input)
Physical → Electrical Signals

Sensors capture physical parameters from the environment (e.g., temperature, humidity, ambient light, distance, motion) and convert them into voltage or digital telemetry.

MCU
2. Processing & Control
Microcontroller / Edge Logic

Microcontrollers (like Arduino ATmega328P or ESP32) read inputs, process algorithmic conditions, compute threshold rules, and command output lines.

ACT
3. Actuation (Physical Output)
Electrical → Physical Action

Actuators convert electrical commands from the microcontroller into physical actions: switching on high-voltage relays, turning motors, sounding alarms, or illuminating LEDs.

NET
4. Connectivity & Cloud
Telemetry, Dashboards & AI

Transmits aggregated sensor data via Wi-Fi, BLE, MQTT, or HTTP to cloud servers for data logging, real-time alerting, machine learning analytics, and remote mobile app control.

Chapter 05

Digital Signals, Analog Signals & PWM

Master the signal principles governing microcontroller inputs and outputs with an interactive waveform generator.

Signal Type: Digital Discrete Binary Voltage: 0V (LOW) ↔ 5V (HIGH) Duty Cycle: 50%
Digital Signals

Only 2 distinct states exist: LOW (0V / logic 0) and HIGH (5V / logic 1). Used for buttons, switches, relay control, and LED on/off states via digitalRead() and digitalWrite().

Analog Signals

Continuous voltages between 0V and 5V. The microcontroller uses an ADC (Analog to Digital Converter) to quantize this range into discrete integers (0 to 1023) via analogRead().

Pulse Width Modulation (PWM)

A technique to simulate variable analog output using rapid digital square waves. By adjusting the Duty Cycle (ratio of ON time to total period), effective voltage and LED brightness are smoothly controlled.

Chapter 06

GPIO & I/O Operations

Understand pin modes, pull-up/pull-down resistor networks, and basic embedded C++ control syntax.

Pin Configuration Modes

  • 1
    pinMode(pin, OUTPUT): Configures the GPIO pin in low-impedance mode capable of providing up to 20mA current to drive LEDs, buzzers, and relay inputs.
  • 2
    pinMode(pin, INPUT): High-impedance mode for sampling external circuit voltages without loading the source.
  • 3
    pinMode(pin, INPUT_PULLUP): Activates the internal 20kΩ pull-up resistor connected to 5V. Default unpressed state reads HIGH; pressing button connects to GND reading LOW.

Why are Pull-Up Resistors Required?

When a push button is open in a standard circuit without a resistor, the microcontroller pin is left disconnected in a floating state. Atmospheric electromagnetic noise can cause the pin to randomly fluctuate between 0 and 1. A 10kΩ pull-up resistor holds the pin securely at 5V (HIGH) until physically pulled down to GND.

[Note]
Current-Limiting Resistor: An LED should always be connected in series with a 220Ω resistor to restrict forward current and prevent thermal runaway.

Chapter 08

How the ARCIO Simulator Works

Learn the mechanics of the virtual simulation engine, canvas interactions, wire routing, and telemetry pipeline.

Simulation Execution Loop

1. Component Graph

When you drag components onto the canvas, ARCIO initializes component objects with active electrical ports and internal state variables.

2. Dynamic Netlist Evaluation

Connecting ports creates dynamic wire nodes. When an input state changes (e.g. clicking a push button), electrical potential propagates through the netlist.

3. Virtual Firmware Engine

The simulation loop reads digital/analog inputs, evaluates the experiment logic (or custom C++ code), and renders animated outputs on the canvas.

Canvas Controls & Shortcuts

  • 1
    Placing Components: Drag any component from the Left Sidebar onto the Canvas. You can reposition components by dragging their header.
  • 2
    Wiring Terminals: Click a component terminal port (circle dot) → move your mouse to the target microcontroller pin → click to complete the wire connection.
  • ⌨️
    Deleting Items: Click a component to select it (cyan border highlight), then press Delete or click the red Remove button.
  • ▶️
    Simulation Run: Click Analyze Circuit to verify connections, then click Run Simulation to activate real-time interactive signals.
Chapter 09

Smart Inspector & Circuit Analyzer

Learn how the automated Circuit Analyzer diagnoses connections, catches mistakes, and inspects live GPIO signals.

Automated Diagnostic Checks

The Right Panel in every ARCIO experiment contains the Circuit Analyzer, which continuously runs static rule checks:

  • *
    Component Presence: Verifies that all required controllers, sensors, and actuators are placed on the canvas.
  • *
    Pin Mapping Accuracy: Checks whether input wires route to the specified GPIO pins defined in the experiment firmware.
  • *
    Closed Loop Continuity: Validates return ground (GND) and power (VCC) connections to prevent open circuits.

Circuit Health Badge States

● Verified / Healthy

All connections match the expected schematic. Ready to start simulation!

● Incomplete Circuit

Missing wire between component port and the assigned GPIO pin.

● Conflict / Error

Short circuit detected or output port wired incorrectly to another output.

LED Blink & Digital Output

Objective & Concept

Required Components

  • 1 Microcontroller Board (Arduino UNO / ESP32)
  • 2 5mm Red/Green LED
  • 3 220Ω Current-Limiting Resistor
  • 4 Virtual Jumper Wires

Pin Connection Mapping

Component Terminal Board Pin Signal Type
LED Anode (+) via 220Ω Resistor GPIO 5 / Pin 13 Digital Output (5V)
LED Cathode (-) GND 0V Common Ground

Arduino C++ Firmware

exp01_led_blink.ino
void setup() { pinMode(5, OUTPUT); // Configure GPIO 5 as digital output } void loop() { digitalWrite(5, HIGH); // Turn LED ON (5V) delay(1000); // Wait 1000 ms (1 second) digitalWrite(5, LOW); // Turn LED OFF (0V) delay(1000); // Wait 1000 ms (1 second) }

Step-by-Step Procedure

  1. 1 Open the experiment by clicking the Open Experiment button below.
  2. 2 From the Left Component Library, drag the Microcontroller onto the simulation canvas.
  3. 3 Drag an LED and place it on the canvas next to the board.
  4. 4 Click the Pin 13 / GPIO 5 port on the board, then click the LED positive terminal port to connect them.
  5. 5 Click Analyze Circuit on the top bar. Verify that Circuit Health reports Healthy.
  6. 6 Click Run Simulation. Observe the LED glowing bright green/red and turning off in 1-second cycles.
[Tip]
Expected Output: The LED on the canvas alternates between ON (illuminated with glowing aura) and OFF at strict 1.0-second intervals. System logs display GPIO 5: HIGH and GPIO 5: LOW.

XP & Leveling Progression

Every completed laboratory experiment awards experience points (XP) that increase your engineer level:

  • 1 Level 1 (0 – 49 XP): ESP32 Newcomer
  • 2 Level 2 (50 – 99 XP): Circuit Apprentice
  • 3 Level 3 (100 – 199 XP): IoT Specialist
  • 4 Level 4 (200 – 299 XP): Automation Pro
  • 5 Level 5 (300+ XP): Master IoT Engineer

Certificate Eligibility & Locking

When all 10 Virtual Experiments reach 100% completion, the Certificate button unlocks on your Dashboard.

[Important]
Permanent Name Locking: Before generating your certificate, you must enter your official student name and registration number. Once confirmed, this name is permanently locked into the cryptographic certificate record and cannot be edited later.

Generated certificates can be printed directly or downloaded as high-resolution PDF documents complete with your unique Certificate ID and institutional verification seal.

Troubleshooting & FAQ

Quick solutions to common circuit assembly, browser rendering, and simulation questions.

Common Simulation Questions

Q: The LED won't illuminate when I run the simulation.

Solution: Verify that the LED positive terminal is connected to the exact pin specified in the code (e.g. GPIO 5), and that the negative terminal connects to GND. Click Analyze Circuit to check for open connections.

Q: The button does not respond when clicked.

Solution: Ensure the simulation is currently Running (green topbar status indicator). Push buttons in ARCIO must be held down with the mouse cursor to maintain contact.

Q: My progress or XP is not saving after completing an experiment.

Solution: Ensure you are logged into your ARCIO student account. Local progress is synced securely with Firebase. Refresh the dashboard if network latency delayed the sync.

Q: I found an issue or need assistance with my lab evaluation.

Solution: Use the Share Feedback link in the dashboard header or reach out directly to your laboratory instructor.

Chapter 15

Quick Reference & Cheat Sheet

Key Arduino C++ functions, resistor color charts, and electrical formulas for rapid lookup.

Core Arduino C++ Functions

pinMode(pin, mode) Set pin as INPUT, OUTPUT, or INPUT_PULLUP
digitalWrite(pin, val) Set pin output to HIGH (5V) or LOW (0V)
digitalRead(pin) Read binary voltage state (returns 0 or 1)
analogRead(pin) Read ADC voltage (0 to 1023 on Uno, 0 to 4095 on ESP32)
analogWrite(pin, val) Generate 8-bit PWM wave with duty cycle (0 to 255)
pulseIn(pin, val) Measures duration in microseconds until pulse changes
delay(ms) Pauses program execution for specified milliseconds

Essential Formulas & Ohm's Law

Voltage = Current × Resistance
Electrical Power:
