Aim
To integrate an ultrasonic distance sensor, a servo-actuated barrier, indicator LEDs and a buzzer with an ESP32 to build a functioning automated parking gate — the capstone experiment combining every concept from Experiments 1–9.
Objective
Continuously measure the distance to an approaching vehicle using an HC-SR04 ultrasonic sensor, and use that reading to automatically raise a barrier gate (servo), switch indicator LEDs, and sound a short buzzer alert — then reverse the sequence once the vehicle has cleared the gate.
Components Used
  • ESP32 (Dual-core, digital + PWM I/O)
  • HC-SR04 Ultrasonic Sensor — TRIG (GPIO5), ECHO (GPIO18)
  • SG90 Servo Motor — barrier arm (GPIO13, PWM)
  • Green LED — gate open indicator (GPIO21)
  • Red LED — gate closed indicator (GPIO22)
  • Active Buzzer — entry alert (GPIO23)
  • 220Ω resistors (LEDs) · Breadboard & jumper wires
Procedure
  • Click Analyze Circuit to confirm all six required wires are connected
  • Click Run Simulation to power up the ESP32 and arm the sensor loop
  • Move the vehicle toward the sensor with the distance slider
  • When distance drops below 30 cm, the ESP32 opens the gate automatically
  • Continue reducing distance until the vehicle clears the sensor to close the gate
  • Use Step to nudge the vehicle 15 cm at a time for a guided walkthrough
Expected Output
While distance ≥ 30 cm the gate stays CLOSED with the red LED lit. Once distance < 30 cm, GPIO13 drives the servo to 90°, the barrier rises, the green LED turns on and the buzzer beeps briefly. After the vehicle passes into the slot, the servo returns to 0°, the gate lowers and the red LED returns — the live values panel reflects each transition in real time.
Learning Outcome
Sensors provide input. The ESP32 processes it. Actuators and output devices respond. Students learn to fuse an analog-style ranging sensor, actuator control, and multi-output signalling into one coordinated state machine — the same pattern used in real-world access control, smart parking, and automated barrier systems.
